Widgets

The dashboard is made of widgets that you arrange on a grid. Layouts are JSON the server keeps, and presets ship with Quarterdeck: the first is Board, then the Planner, Driver and Notebook as tabs, then Events.

The dashboard is still being built, so this page says what each widget is for, not what it looks like. Every widget shows state the server streams to it; anything you do in one is sent to the server, which is the only thing that changes state.

Board

Whether everything is alive. The Board shows the stream's status, then each picked project with its live agents, tagged paused or archived. Pause all stops new work in every project and the Board then says Paused everywhere; Resume all undoes it. Up to four projects are shown at once: the first four by name until you pick, and archived projects only when Show archived is on.

Project

One project: its repository and its crew.

Agents

The crew: the Planner, the Driver, the builders and the reviewer, with each agent's runtime and latest status.

Events

Everything that happened in the project, in order, as it happens.

Cards

Decisions waiting for you: permission requests, questions from agents, merges, sign-ins. A declined or unanswered card is a result the agent sees, not a crash.

Planner

Your conversation with the Planner, which turns what you describe into tickets for you to approve.

Driver

The Driver's work: which builder has which ticket, and what it is doing about each.

Notebook

What earlier Drivers learned about the project. Each new Driver is born with it.

Usage

Tokens spent by agents and tickets, against the budget.

Rules

The rules files, edited in place. Edits are saved as rules.local.* files and checked before they are written.

Data

Every table Quarterdeck keeps for the project with its row count, and its rows a page at a time, newest first. Below them, every path on disk the project uses and whether it exists yet, with a Wipe button for one project and one for everything. See where your data lives.
