Quarterdeck for Kiro

Run a crew of Kiro and Claude Code agents from one local board.

One process on your machine. It starts agents through their own CLIs, hands them tickets, reviews their pull requests, merges the ones that pass, and stops for you only when a decision is irreversible or product-shaped.

  • No API keys
  • No account
  • No telemetry
  • Your data in one folder
npx quarterdeck up

New here? Start with the quickstart, then read about rules, widgets, where your data lives and the FAQ. Or try the demo: the real dashboard playing scripted rounds in your browser, connected to nothing.
